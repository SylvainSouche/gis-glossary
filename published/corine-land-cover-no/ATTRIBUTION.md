# CORINE Land Cover nomenclature, Bokmål and English

- **Credit:** Norsk institutt for bioøkonomi (NIBIO), formerly Norsk institutt for skog og
  landskap; Linda Aune-Lundberg and Geir-Harald Strand. The Bokmål class names derive from a
  list by a project group of the Norwegian Ministry of Environment (NIJOS report 11/1997 part 4).
  English class names: CORINE Land Cover nomenclature, European Environment Agency.
- **Source:** *CORINE Land Cover 2006. The Norwegian CLC2006 project*, Rapport fra Skog og
  landskap 11/2010, ISBN 978-82-311-0114-7, appendix 6.3.
- **Licence:** the report states none. The same codes and Bokmål names form the legend of
  NIBIO's dataset *Corine Landcover (CLC) Norge*, published under the Norwegian Licence for
  Open Government Data (NLOD 1.0), <https://data.norge.no/nlod/no/1.0>; legend document:
  <https://register.geonorge.no/tegneregler/clc-corine-land-cover>. Only class names and codes
  are kept here.
- **Retrieved:** 2026-11-13, from a copy of the report supplied by the project owner.
- **Changes:** the 64 classes of levels 1 to 3 extracted to CSV; codes written without dots
  (311 for 3.1.1); `in_norway` records the report's marks (absent, too small).
