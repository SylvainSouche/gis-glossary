# Published

Term lists generated by this project from its sources. Regenerate them with their
scripts rather than editing them by hand. Each folder has an `ATTRIBUTION.md`.

| Folder | Content | Generated by |
|---|---|---|
| `iso-mlgt/` | ISO/TC 211 MLGT term equivalents, without definitions | `tools/publish_mlgt.sh` |
| `corine-land-cover-no/` | CORINE Land Cover nomenclature, 64 classes, Bokmål and English, keyed by CLC code | extracted from the NIBIO CLC2006 report |
| `gemet/` | GEMET labels (EEA environmental thesaurus), 5,609 concepts and groups in 15 target languages; CC BY 4.0 | `tools/extract_gemet.py` |
| `geonorge-metadata-codelists/` | Geonorge metadata code list names, Bokmål and English, paired by item id; no descriptions | `tools/extract_geonorge.py codelists` |
| `geonorge-resources/` | Geonorge web application interface strings, Bokmål and English, pinned commits | `tools/extract_geonorge.py resources` |
| `arnastofnun-dictionaries/` | Árni Magnússon Institute dictionaries (ISLEX is→da/nb/nn/sv/fo/fi, Icelandic-French, Icelandic-Polish), one row per translation, with phrases and example sentences; CC BY-SA 4.0 | `tools/extract_arnastofnun.py` (run on GitHub Actions) |
| `arnastofnun-en-is-glossary/` | Árni Magnússon Institute English-Icelandic glossary 21.09, 229,299 pairs with method counts and scores; CC BY 4.0 | copied from CLARIN-IS with a header row |
| `iate/` | GIS-related IATE terms selected from the export; candidates | `tools/extract_iate.py` |
| `lisa/` | LÍSA Icelandic-English GIS term pairs, without definitions | `tools/extract_lisa.py` |
| `qgis-gui/` | QGIS interface labels from a pinned commit, compressed | `tools/extract_qgis_gui.py` |
| `qgis-manual-headings/` | QGIS manual headings aligned across languages; raw candidates | `tools/extract_qgis_headings.py` |
