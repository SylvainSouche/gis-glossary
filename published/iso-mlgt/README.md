# ISO/TC 211 Multi-Lingual Glossary (held back)

Permission to use this resource has been asked of ISO/TC 211; pending their answer, the data is
held back. The extractor (`tools/extract_mlgt.py`, run by
`tools/publish_mlgt.sh`) is in the repository; the generated `mlgt_terms.csv` is kept out of git,
and a build from this repository runs without it.

## The resource

The ISO/TC 211 Multi-Lingual Glossary of Terms is the terminology register of the ISO technical
committee for geographic information and geomatics: about 1,500 concepts from the ISO 19100
standards, with terms and definitions in up to 15 languages.

- Register owner: ISO/TC 211; register manager: the ISO/TC 211 Terminology Maintenance Group
- Site: <https://isotc211.geolexica.org>
- Source data: <https://github.com/geolexica/isotc211-glossary>
