# INSPIRE regulation: official names of spatial object types, data types and code lists

- **Source:** Commission Regulation (EU) No 1089/2010 of 23 November 2010 implementing
  Directive 2007/2/EC as regards interoperability of spatial data sets and services, as amended.
  - EU languages: consolidated version 02010R1089-20231119, from the Publications Office
    (Cellar API), <https://eur-lex.europa.eu/eli/reg/2010/1089/oj>.
  - Bokmål: EØS-tillegget til Den europeiske unions tidende, no. 64/2016 (1089/2010) and
    no. 28/2019 (1253/2013).
  - Icelandic: EES-viðbætir við Stjórnartíðindi Evrópusambandsins, no. 67/2012 (1089/2010) and
    no. 16/2015 (1253/2013).

- **Changes:** headings that end with a technical name, such as "Hydro Node (HydroNode)", are
  extracted by `tools/extract_inspire_reg.py`: one row per technical name and language, with the
  section number and act. The technical name is the key across languages. Definitions are not
  kept. Bokmål and Icelandic cover the base act and amendment 1253/2013 only (not 102/2011,
  1312/2014 or later amendments).
